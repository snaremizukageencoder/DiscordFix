> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
> WinDivert иногда вызывает реакцию антивируса.  
> Это средство перехвата и фильтрации трафика, без которого zapret не работает.
> WinDivert может применяться как безопасными, так и вредоносными программами, однако сам вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) из репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов считает файлы WinDivert инструментами повышенного риска или хакерскими утилитами. В результате файл удаляется и попадает в карантин. Название обнаружения при этом обычно содержит `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с запретом в исключения антивируса или отключите обнаружение PUA (потенциально нежелательных приложений). Например, в Kaspersky есть параметр "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". При уверенной настройке исключений предпочтительнее добавить исключение, но если вы не вполне понимаете последствия, рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите безопасный DNS (Secure DNS).
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика услуг DNS — не вариант "Поставщик по умолчанию".
    * В Firefox откройте "DNS через HTTPS", выберите режим "Персональный", затем "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку провайдер Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11.
    * На роутерах Keenetic активируйте параметр "Транзит запросов". Если его отключить, Secure DNS на компьютере может работать неправильно.

2. Загрузите zip- или rar-архив с [последнего релиза](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases/latest).

3. Откройте свойства архива и установите флажок "Разблокировать". При использовании 7-Zip или PeaZip этот шаг не требуется.

4. Извлеките файлы в каталог, в пути к которому нет кириллицы и специальных символов.

5. Запустите подходящий файл.
    * Для поиска рабочей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автоматический запуск, выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии.

  Такой запуск удобен для проверки стратегий. Результат зависит от множества условий, поэтому **перебирайте разные варианты (ALT, FAKE и другие), пока не найдёте подходящий для себя**.

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные операции:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из служб
  - **`Check Status`** — просмотр состояния обхода и служб, включая стратегию автозапуска и WinDivert
  - **`Game Filter`** — изменение режима обхода для игр и других сервисов, работающих с UDP и TCP на портах выше 1023.  
  **После изменения параметра стратегию нужно перезапустить.**  
  Текущее состояние (включено или выключено) отображается в скобках.
  - **`IPSet Filter`** — изменение режима обхода для сервисов, перечисленных в `ipset-all.txt`.  
  Опция полезна при проверке ресурса, который без zapret работает, а с ним — нет.  
  В скобках показывается выбранное состояние:
    - `none` — ни один IP не проходит проверку
    - `loaded` — IP проверяются по списку
    - `any` — под фильтр попадает любой IP  
  - **`Auto-Update Check`** — включение или отключение автоматической проверки обновлений
  - **`Replace active fakes`** — замена используемого фейка на другой из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для исправления веб-версии Telegram и подключения к голосовому чату Discord**</ins>
  - **`Check for Updates`** — ручная проверка обновлений
  - **`Run Diagnostics`** — поиск распространённых причин, из-за которых zapret может не работать.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность, если приложение внезапно перестало работать.
  - **`Run Tests`** — проверка стратегий специальной утилитой:
    - `Standard tests` — проверка сайтов из `utils/targets.txt`
    - `DPI checkers` — проверка DPI у разных провайдеров, включая Cloudflare и Amazon


## ☑️Распространенные вопросы и проблемы

### После запуска скрипта `general*` ничего не происходит

После запуска стратегии отдельным bat-файлом, а не через service, должен появиться winws.exe (обход), видимый на панели задач.  
Если программа не появилась, обратитесь к [#522](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/522).

### Ни одна стратегия не подходит
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не работает телеграм (веб версия)

Откройте **`service.bat`** и запустите **`Update hosts file`**. Если файл hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открывшегося блокнота.
  - Запустите текстовый редактор от имени администратора и откройте файл `hosts` в созданной папке.
  - Вставьте скопированный текст в конец `hosts` либо замените аналогичные строки, если вы уже добавляли их ранее.
  - Сохраните файл и снова проверьте подключение. Если результата нет, убедитесь, что сохранение действительно выполнено.

#### Работа не гарантирована. Если способ не помог, используйте [Desktop-версию](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/snaremizukageencoder/tg-ws-proxy) или любым публичным прокси.

### Обход не работает / перестал работать

> [!IMPORTANT]
> **Стратегии могут со временем терять работоспособность.**
> Вначале определённая стратегия может помогать, но после обнаружения перестать работать.
> В репозитории есть много вариантов обхода. Если ни один не подходит, создайте новый вариант на основе представленной стратегии, изменив её параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Убедитесь, что в `service.bat` -> `Run Diagnostics` не обнаружены ошибки.

- Проверьте, внесён ли адрес ресурса в списки доменов или IP.

- Проверьте другие стратегии, в том числе (**`ALT`**/**`FAKE`**).

- Выполните полную переустановку по инструкции ниже.

- См. [#765](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues/765).

### Как переустановить/обновить полностью?
- Сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте ошибки, если они есть, затем в конце выберите Y.
- Удалите каталог с запретом.
- Скачайте свежую версию [со страницы релизов](https://github.com/snaremizukageencoder/zapret-discord-youtube/releases) (`zapret-discord-youtube-...`).
- Откройте свойства архива правой кнопкой мыши. Если внизу справа есть флажок разблокировки, установите его, нажмите «Применить» и «ОК».
- Распакуйте архив в новую папку в корне диска; в пути не должно быть специальных символов и пробелов.
- Запускайте разные скрипты `general` и проверяйте интернет-ресурсы. Если доступ не появился, закройте программу через значок замка на панели задач и попробуйте следующую стратегию.
- После выбора рабочей стратегии добавьте её в автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Не работает игра/приложение с включённым запретом

- В `service.bat` проверьте, что `Game Filter` имеет значение **`disabled`**, а `IPSet Filter` — **`none`**. Иначе обход может повлиять на ресурсы, которые вы не планировали фильтровать.

### Античит ругается на WinDivert

- Ознакомьтесь с инструкцией: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Требуется цифровая подпись драйвера WinDivert (Windows 7)

- Замените `WinDivert.dll` и `WinDivert64.sys` в [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### При удалении с помощью [**`service.bat`**](./service.bat), WinDivert остается в службах

1. Найдите имя службы командой в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал с ними бороться.
- Если раньше всё работало, проверьте все остальные стратегии.
- См. также [#251](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Сначала желательно определить стратегию, на которой открывается YouTube, и запустить её.
- В `service.bat` откройте `Run Diagnostics` и очистите кэш Discord.
- Проверьте приложение Discord и выясните, помогла ли очистка кэша.
- Откройте Discord в браузере: https://discord.com/app. Если браузерная версия работает, можно пользоваться ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. YouTube и Discord могут работать на разных стратегиях.
- См. также [#252](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/snaremizukageencoder/tg-ws-proxy).
- Либо воспользуйтесь бесплатными MTProto-прокси из интернета.

### Не работают игры

Игр много, поэтому проверить и исправить каждую из них невозможно.

Обычно стоит сделать следующее:
- Обновить ipset через `service.bat` и включить `Game Filter`.
- Если это не помогло, дополнительно включить `ipset any`.

Учтите: при включённом `ipset any` многие сайты могут перестать открываться. Не оставляйте этот режим включённым постоянно. Определите IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`.

Если проблема сохраняется, создайте обсуждение в разделе [Discussions](https://github.com/snaremizukageencoder/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### Не нашли своей проблемы

- Опишите её [здесь](https://github.com/snaremizukageencoder/zapret-discord-youtube/issues).

## 🗒️Добавление адресов прочих ресурсов

Новые адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** — домены; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** — домены-исключения, например когда IP сети есть в `ipset-all.txt`, но конкретный домен этой сети фильтровать не нужно.
- **`ipset-all.txt`** — IP-адреса и подсети.
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
